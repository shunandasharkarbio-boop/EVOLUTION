
# 🧬 Identifying Tuberculosis Transmission Links

### Galaxy Training — Hands-on Learning Project

> 📚 A hands-on bioinformatics exercise completed while learning through the
> Galaxy Training Network (GTN).

---

## 🧪 About This Project

This project is part of my ongoing journey of learning bioinformatics
using the **Galaxy platform**.

I followed the Galaxy Training Network tutorial:

**"Identifying tuberculosis transmission links: from SNPs to transmission clusters"**

The tutorial explores how genomic variation can be used to identify
possible transmission clusters among *Mycobacterium tuberculosis* samples.

---

## 🎯 Objectives

Through this tutorial, I learned how to:

- 🧬 Create a SNP alignment
- 📊 Calculate pairwise SNP distances between MTB samples
- 🔗 Identify possible transmission clusters
- 🧪 Combine transmission-cluster information with drug-resistance profiles
- 🧬 Explore the relationship between genetic similarity and transmission

---
